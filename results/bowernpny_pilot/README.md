# Bowern-PNY IQ-TREE pilot

Pilot phylogenetic analysis of 24 Australian varieties using 540 variable shared cognate characters.

## Dataset

- Selected varieties: 24
- Variable shared cognate characters: 540
- Singleton cognate sets: excluded
- Constant characters: excluded
- Missing concepts: `?`
- Present-but-different cognates: `0`
- Shared cognates: `1`

## Analysis

Maximum-likelihood phylogenetic inference was performed with IQ-TREE.

The analysis was generated automatically by the repository's GitHub Actions workflow.

## Result

The resulting tree is stored as:

`bowernpny_pilot.treefile`

The tree includes branch lengths and IQ-TREE support values.

## Status

This is a pilot analysis intended for methodological inspection and further refinement.
